# April 2026 GDK capability audit

Audit date: 2026-09-24. Target: Windows PC, x64, D3D12, static PPC-to-C++ ReXGlue titles. The [April 2026 release notes](https://learn.microsoft.com/en-us/gaming/gdk/docs/gdk-dev/whatsnew/whats-new?view=gdk-2604), [GDK features index](https://learn.microsoft.com/en-us/gaming/gdk/docs/features/features-index?view=gdk-2604), and [PC tools index](https://learn.microsoft.com/en-us/gaming/gdk/docs/tools/tools-index?view=gdk-2604) are the public inventory. Issue and PR states below were checked against `furqanagwan/rexglue-sdk` and `furqanagwan/007` on this date.

| Capability | SDK ownership and disposition | Tracking |
| --- | --- | --- |
| April 2026 PC toolchain, VS 2026, Windows SDK and reproducible builds | Required before native GDK integrations. GDK 260404 is installed locally, but the current `win-amd64` preset does not select it. VS Community is installed; the release notes explicitly name Professional and Enterprise support. Record this distinction and prove the actual compiler/CRT/consumer pairing. | [RG-GDK-002](https://github.com/furqanagwan/rexglue-sdk/issues/2) |
| D3D12 graphics, shader toolchain, GPU capabilities and vendor evidence | Core SDK work. Keep graphics behavior and profiling independent of any one title. AMD and Intel hardware validation is unavailable locally and non-blocking per ADR-007. | [RG-GDK-006](https://github.com/furqanagwan/rexglue-sdk/issues/6), [RG-GDK-007](https://github.com/furqanagwan/rexglue-sdk/issues/7), [RG-GDK-009–012](https://github.com/furqanagwan/rexglue-sdk/issues/9), [ADR-007](adr/ADR-007-local-gpu-validation-scope.md) |
| GameInput | Core host input adapter; preserve guest slots, focus, rumble and subtype semantics. PC GameInput comes via its NuGet/redist package, not just the GDK install. | [RG-GDK-020](https://github.com/furqanagwan/rexglue-sdk/issues/20) |
| XAudio2 | Core host PCM output with guest XMA behavior kept separate. | [RG-GDK-018](https://github.com/furqanagwan/rexglue-sdk/issues/18), [RG-GDK-019](https://github.com/furqanagwan/rexglue-sdk/issues/19) |
| Gaming Runtime lifecycle, MicrosoftGame.config and stable packaging | Title-template/SDK boundary. Use title-supplied identity. April 2026 MSIXVC2 is preview and barred from public certification, so retain the stable package path. Submission Validator and sandbox tools belong to packaging/test instructions, not the runtime library. | [RG-GDK-022](https://github.com/furqanagwan/rexglue-sdk/issues/22) |
| User identity, XUser, saves, achievements, Xbox services and PlayFab | Guest XAM identity/persistence must work without a host Xbox identity. Investigate optional host services per title only after a real identity, entitlement and data model exist. Do not map guest accounts to host accounts implicitly. | [RG-GDK-017](https://github.com/furqanagwan/rexglue-sdk/issues/17), [RG-GDK-022](https://github.com/furqanagwan/rexglue-sdk/issues/22) |
| XTaskQueue and asynchronous runtime facilities | Evaluate only where GDK APIs require them; preserve existing guest timing, callbacks and shutdown semantics. | [RG-GDK-015](https://github.com/furqanagwan/rexglue-sdk/issues/15), [RG-GDK-022](https://github.com/furqanagwan/rexglue-sdk/issues/22) |
| PIX for Windows | SDK-owned D3D12 diagnostics. `GetGraphicsAnalysisInterface` already detects PIX, but reproducible capture, event markers and capture review are missing. Guest `PIX*` exports are a separate compatibility concern. | [RG-GDK-028](https://github.com/furqanagwan/rexglue-sdk/issues/41) |
| DirectStorage on PC | Optional host I/O optimization, not a requirement to make Xbox 360 file calls correct. Profile real file access and compare against existing I/O first; require a fallback and preserved guest ordering. The April release note describes **PIX displaying packaged DirectStorage file mappings**, not a new mandatory DirectStorage integration. | [RG-GDK-029](https://github.com/furqanagwan/rexglue-sdk/issues/42) |
| Xbox console-specific DirectStorage, native ARM64 preview, Xbox-only tools | Outside the initial x64 PC target. Reassess only if the supported platform changes. | No implementation issue |

The April 2026 notes also mention `wdcapturesession` only in the October 2025 section; it may aid manual title evidence, but it is not a core SDK dependency. PC Sandbox Switcher and Submission Validator are deployment/testing tools covered by RG-GDK-022. The April MSIXVC2 and ARM64 items are previews and are excluded from the stable acceptance gate. Keep per-game performance or compatibility findings in that game's repository, with a linked SDK issue for shared fixes.

The next implementation order is: prove RG-GDK-002, integrate GameInput/XAudio2 and PC lifecycle at their existing boundaries, add PIX profiling to the D3D12 baseline, then decide DirectStorage from measured I/O. The audit is a scope and dependency map; it does not claim any GDK runtime, PIX capture or DirectStorage validation has passed.
