# Source task markers

Unresolved source notes now live in research and linked investigation issues,
instead of informal task markers in implementation files. This fulfills the
marker migration in [#229](https://github.com/furqanagwan/rexglue-sdk/issues/229);
it does not claim to fix the inherited hardware or runtime questions.

The 2026-10-10 lexical inventory of SDK
`7ec3b080f65e9e94eacbf3b1dbd8f999f3ae216e` found 370 C++/shader marker comments
across 121 files and two inactive CMake reminders. The earlier substring-based
audit also counted `kXXXX` swizzles, hexadecimal placeholders and other uses of
`XXX` that are not task markers. Those names and representations stay intact.

Each note's full original comment, author tags, source pin and line location
are retained under [remaining work](remaining-work/README.md). Ten comment
reminders concern retired Vulkan/Metal hosts, CPU-JIT interfaces or upstream
applications that this static SDK does not provide. They are explicitly marked
retired. The two disabled JIT build entries have their own
[retirement record](remaining-work/retired-jit-build-reminders.md). No active
build entry, compatibility workaround or implementation is removed.

The other 360 notes remain investigation tasks in 20 topic issues. They are
inherited uncertainties, not demonstrated defects. Before implementing one,
compare current behavior and existing work, obtain the required architecture
decision where applicable, and establish measurable regression gates. Closing
this cleanup issue does not close those investigations.

## Validation

- The initial comment extraction and pinned clang-format 20.1.8 preserve all
  non-comment tokens in the 121 affected C++/shader files. The final candidate
  additionally spells two pointer conversions in `src/system/lzx.cpp` as
  `reinterpret_cast`, preserving the same types and byte-offset arithmetic.
- There are no word-delimited TODO, FIXME, HACK or XXX task markers in SDK
  `src` or `include`. Functional swizzle identifiers are not renamed.
- All 108 shaders pass `scripts/build_shaders.py --check` with Windows SDK
  10.0.26100.0 FXC; no bytecode headers are edited.
- Roadmap validation, documentation link/path checks and `git diff --check`
  pass. Runtime/CI validation is recorded in the pull request before merging.

Removing a trailing comment exposes the existing casts to changed-line
analysis. Their spelling is made explicit rather than suppressing that check.
The naming configuration also recognizes the SDK's required PascalCase
`_entry` export suffix; the guest export and registration names stay intact.

The extraction excludes generated bytecode and third-party code. Guide source
comment migration belongs to [#230](https://github.com/furqanagwan/rexglue-sdk/issues/230)
and the Guide repository. Its implementation is unaffected here.
